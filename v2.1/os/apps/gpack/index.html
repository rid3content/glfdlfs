Как это устроено

gPST — рабочий модуль gpack

gPST расшифровывается как program-specific tools — набор специализированных генераторов, каждый заточен под синтаксис своей технологии.

1. Выберите технологию

PostgreSQL, Redis, Nginx, Docker, YAML или JSON.

2. Заполните параметры

Форма покажет только те поля, которые нужны именно этой технологии.

3. Заберите файл

Скопируйте или скачайте готовый конфиг — сразу с нужным расширением.
